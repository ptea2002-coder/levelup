# LevelUP — website gaming

Đây là phiên bản website LevelUP viết bằng HTML, CSS và JavaScript thuần. Mình chọn bản gọn để bạn mới dùng GitHub có thể đưa website lên mạng dễ hơn, không cần cài Node.js hay chạy lệnh.

## Chạy thử
Mở file `index.html` bằng trình duyệt.

## Đưa lên GitHub
1. Vào https://github.com/new và tạo repository tên `levelup`.
2. Chọn **Add file → Upload files**.
3. Giải nén file ZIP này trên máy tính.
4. Kéo file `index.html` và `README.md` vào vùng upload của GitHub.
5. Nhấn **Commit changes**.

## Đưa website lên Vercel
1. Vào https://vercel.com/signup và đăng nhập bằng GitHub.
2. Chọn **Add New… → Project** rồi import repository `levelup`.
3. Nếu Vercel hỏi cấu hình, chọn Framework Preset **Other**; để Build Command trống và đặt Output Directory là `.`.
4. Nhấn **Deploy**. Khi hoàn tất, Vercel sẽ đưa cho bạn một đường link công khai.

## Ghi chú
- Đây là giao diện front-end demo; nội dung game và số liệu là nội dung minh họa.
- Tìm kiếm và lọc thể loại trong danh sách game hoạt động ở phía trình duyệt.
- Chưa có tài khoản thành viên, cơ sở dữ liệu, quản trị nội dung hay hệ thống gửi email.
- Ảnh và font chữ tải từ internet nên cần kết nối mạng.
